# Задача 7
## Условие задачи

Информационно-вычислительная система имеет 5 серверов. Каждый сервер подвергается атакам через интервалы времени, распределенные экспоненциально со средними, которые составляют для этих серверов 14, 26, 32, 64, 70 час., соответственно.
Из числа всех атак только 30% представляют серьезную угрозу безопасности, при которой сервер полностью выходит из строя, 20% приводит к частичному выходу сервера из строя, а в остальных 50% случаев система безопасности обеспечивает надлежащую защиту серверов.
Для выполнения работ по восстановлению работоспособности серверов предприятие имеет некоторое количество системных программистов, каждый из которых одновременно может работать только с одним сервером.
Время восстановления работоспособности сервера при полном выходе его из строя составляет 16±8 час., а при частичном выходе из строя — 8±4 час.
Необходимо определить минимальное число системных программистов, при котором за год среднее число неисправных серверов не превосходило 2.
